Chromebook 児童端末管理クライアント（Chrome 拡張機能）

本プライバシーポリシーは、片岡 靖貴（以下「当方」といいます）が開発・運営する Chrome 拡張機能「Chromebook 児童端末管理クライアント」（以下「本拡張機能」といいます）における、利用者情報の取扱いについて定めるものです。

本拡張機能は、教育委員会・学校（以下「導入先」といいます）の管理する Google Workspace for Education 環境に導入して使用する端末管理用のクライアントです。導入先の許可の下でのみ使用され、児童生徒および一般の個人が、自らの判断で本拡張機能をインストール・利用することを想定していません。

1. 取得する情報

本拡張機能は、導入先が端末を管理する目的の範囲内で、以下の情報を取得することがあります。

情報の種類内容
認証情報端末にログインしている Google アカウントのメールアドレス（chrome.identity API により取得）
個人識別情報導入先が管理する名簿に基づく氏名・所属学校・クラス
Web 閲覧情報端末で現在表示しているページの URL
Web サイトの内容教員が画面確認を指示した場合の、現在表示している画面の画像（スクリーンショット）
利用状況端末とサーバー間の最終通信日時などの同期情報

2. 利用目的

取得した情報は、導入先における次の目的にのみ利用します。

  • 教員による画面ロックおよびロック解除
  • 学習に適さない Web サイトへのアクセス制限（URL 規制：ホワイトリスト／ブラックリスト）
  • 教員が指定した URL の一斉配信
  • 児童生徒の閲覧状況の把握（見守り）および端末の稼働状況の確認
  • 上記に付随する端末管理業務

取得した情報を、上記の目的以外に利用することはありません。

3. 保管および安全管理

  • 取得した情報は、原則として導入先が管理する Google Workspace 組織内のスプレッドシートに保管されます。
  • 通信は HTTPS により暗号化されます。
  • 情報へのアクセスは、導入先が認めた教職員に限定されます。当方が、本拡張機能の保守・運用（不具合対応等）のために必要な最小限の範囲でアクセスする場合があります。
  • 保管期間は、導入先の定めるところにより、当該児童生徒の在籍期間および管理上必要な期間とし、その後は適切に削除されます。

4. 第三者への提供

取得した情報を、外部の第三者へ提供・販売・譲渡することはありません。ただし、導入先の同意がある場合、または法令に基づく開示請求があった場合はこの限りではありません。

5. 広告・解析ツール

本拡張機能は、広告の表示、および第三者のアクセス解析ツールへの情報送信を行いません。

6. 開示・訂正・削除の請求

取得した情報の開示・訂正・削除を希望される場合は、下記のお問い合わせ先までご連絡ください。ご本人（または保護者）であることを確認のうえ、導入先の定めるところにより対応します。実際の情報は導入先が管理しているため、当方より導入先へお取次ぎする場合があります。
