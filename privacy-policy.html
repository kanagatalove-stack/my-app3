プライバシーポリシー

Chromebook 児童端末管理クライアント（Chrome 拡張機能）

本プライバシーポリシーは、美作市教育委員会（以下「当委員会」といいます）が、教育委員会の管理下にある児童生徒の Chromebook 端末の運用管理のために提供する Chrome 拡張機能「Chromebook 児童端末管理クライアント」（以下「本拡張機能」といいます）における、利用者情報の取扱いについて定めるものです。

本拡張機能は、当委員会が管理する Google Workspace for Education 環境において、当委員会の許可の下でのみ使用されます。児童生徒および一般の個人が、自らの判断で本拡張機能をインストール・利用することを想定していません。

1. 取得する情報

本拡張機能は、当委員会が端末を管理する目的の範囲内で、以下の情報を取得することがあります。

情報の種類内容
認証情報端末にログインしている Google アカウントのメールアドレス（chrome.identity API により取得）
個人識別情報当委員会が管理する名簿に基づく氏名・所属学校・クラス
Web 閲覧情報端末で現在表示しているページの URL
Web サイトの内容教員が画面確認を指示した場合の、現在表示している画面の画像（スクリーンショット）
利用状況端末とサーバー間の最終通信日時などの同期情報

2. 利用目的

取得した情報は、次の目的にのみ利用します。

  • 教員による画面ロックおよびロック解除
  • 学習に適さない Web サイトへのアクセス制限（URL 規制：ホワイトリスト／ブラックリスト）
  • 教員が指定した URL の一斉配信
  • 児童生徒の閲覧状況の把握（見守り）および端末の稼働状況の確認
  • 上記に付随する端末管理業務

取得した情報を、上記の目的以外に利用することはありません。

3. 保管および安全管理

  • 取得した情報は、当委員会が管理する Google Workspace 組織内のスプレッドシートに保管します。
  • 通信は HTTPS により暗号化されます。
  • 情報へのアクセスは、当委員会が認めた教職員（管理者・担当教員）に限定されます。
  • 保管期間は、当該児童生徒の在籍期間および当委員会が定める管理上必要な期間とし、その後は適切に削除します。

4. 第三者への提供

取得した情報を、外部の第三者へ提供・販売・譲渡することはありません。ただし、法令に基づく開示請求があった場合はこの限りではありません。

5. 広告・解析ツール

本拡張機能は、広告の表示、および第三者のアクセス解析ツールへの情報送信を行いません。

6. 開示・訂正・削除の請求

取得した情報の開示・訂正・削除を希望される場合は、下記のお問い合わせ先までご連絡ください。本人（または保護者）であることを確認のうえ、当委員会の定めるところにより対応します。
