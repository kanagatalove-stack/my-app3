# プライバシーポリシーを Google サイトで公開する手順

GitHub Pages（`kanagatalove-stack.github.io`）がアカウント停止により 404 になったため、
既存の Google サイトへ移すための資材です。**所要 10〜15分**、コードの知識は不要です。

## このフォルダの中身

| ファイル | 用途 |
|---|---|
| `privacy-policy-embed.html` | **推奨**。Google サイトの「埋め込み」に貼る HTML。元の HTML 版と本文が完全一致（検証済み） |
| `privacy-policy-plaintext.txt` | 埋め込みが使えない場合の代替。テキストボックスにそのまま貼る |

---

## 手順 A：埋め込み（推奨・見た目が整う）

1. Google サイト（新バージョン）で対象のサイトを開きます。
2. 左下の **「ページ」** → **「＋」** → ページ名に `プライバシーポリシー` を入力 → **「完了」**。
   - **1ページのみ**で構いません。サブページも作れますが、ストアにはこの1ページの URL を登録するだけです。
3. 右側の **「挿入」** タブ → **「埋め込み」** → **「埋め込みコード」** を選びます。
4. `privacy-policy-embed.html` の**中身をすべて**コピーして貼り付け → **「次へ」** → **「挿入」**。
5. 枠の右下をドラッグして、**横幅いっぱい・高さは十分に**広げます（目安：高さ 2000px 以上）。
   - 高さが足りないと途中でスクロールバーが出ます。その場合は枠を広げてください。
6. 右上の **「公開」** → 公開範囲を確認して **「公開」**。
7. 公開後、**「公開したサイトを表示」** でページを開き、URL をコピーします。

### URL の形

```
https://sites.google.com/view/<サイト名>/privacy-policy
```

> 📌 ストアに登録するのは **このページの URL** です。サイトのトップページではなく、
> プライバシーポリシーのページを直接開いたときの URL をコピーしてください。

---

## 手順 B：テキストのみ（埋め込みがうまくいかない場合）

1. 手順 A の 1〜2 と同じく、ページを作ります。
2. **「挿入」** → **「テキストボックス」** を選びます。
3. `privacy-policy-plaintext.txt` の中身をすべて貼り付けます。
4. 見出し（`1. 取得する情報` など）を選択して、書式を **「見出し」** にすると読みやすくなります。
5. **「公開」** して URL をコピーします。

---

## 公開前のチェックリスト

- [ ] ページが**誰でも閲覧できる**（「限定公開」や「組織内のみ」になっていない）
      ※ ストアの審査担当者は外部の人間です。**リンクを知っている全員が閲覧可能**にしてください。
- [ ] シークレットウィンドウ（ログアウト状態）で URL を開いて、**表示できる**ことを確認
- [ ] **運営者・開発者：片岡 靖貴** が表示されている
- [ ] **noiringhost@gmail.com** が表示されている
- [ ] 「1. 取得する情報」〜「8. 本ポリシーの改定」まで**最後まで**表示される（埋め込みの高さ不足に注意）

> ⚠️ **一番多い失敗**: 埋め込みの枠が低すぎて途中で切れる／公開範囲が「限定公開」になっていて
> 審査担当者が開けない。この2点だけは必ず確認してください。

---

## 公開後にやること

1. Chrome ウェブストアの **「プライバシー」タブ** → プライバシーポリシーの URL を
   **Google サイトの URL に差し替え**ます。
2. ストアの「サポート URL」も同じ URL か、サイトのトップページに変更します。
3. `docs/CHROME_WEB_STORE_SUBMISSION.md` の §2-5 に書かれた URL も差し替えます（社内資料用）。

> 💡 Google サイトの URL は**変更しないでください**。ページ名やサイト名を変えると URL が変わり、
> ストアに登録したリンクが切れます。
