## 3. 年額ライセンス・保守運用費（経常費用）

### 3.1 料金体系（選択制）

本システムの年額費用は、**14校一括方式**または**児童単価方式**のいずれかを選択できます。いずれも提供内容は同一です。

#### 方式A: 14校一括方式（推奨）

| 項目 | 内容 |
|---|---|
| 年額（税抜） | 〔金 ○,○○○,○○○ 円／年〕 |
| 内訳単位 | 14校一括（端末台数・児童数の増減による変動なし） |
| 月額換算 | 〔金 ○○,○○○ 円／月（税抜）〕 |
| 適用条件 | 対象14校すべてを一括契約する場合 |

**特徴**: 児童数・端末台数が年度途中で変動しても年額が一定のため、**予算計上が容易**です。学級増減（子GAS追加）についても追加費用なしで対応します。

#### 方式B: 児童単価方式

| 項目 | 内容 |
|---|---|
| 児童単価（税抜） | 〔金 ○,○○○ 円／児童・年〕 |
| 年間対象児童数 | 〔○,○○○ 名（〔YYYY年MM月DD日〕時点の名簿による）〕 |
| 年額（税抜） | 〔金 ○,○○○,○○○ 円／年〕（＝単価 × 児童数） |
| 月額換算 | 〔金 ○○,○○○ 円／月（税抜）〕 |
| 最低契約額 | 〔金 ○,○○○,○○○ 円／年〕 |

**特徴**: 児童数の増減に連動するため、**規模変動が大きい場合**に適します。年度途中の転出入による精算は〔年度末一括精算／翌年度に反映〕とします。

> **【選択の目安】** 対象児童数が〔○,○○○〕名を超える場合は方式Aが、下回る場合は方式Bが有利となるよう設定しています。実際の損益分岐点は〔○,○○○〕名です。

## 5. 見積条件

1. 本見積は **税抜表示** を基本とし、消費税は適用時点の法令によります。
2. 本見積の有効期限は作成日より〔90日間〕です。
3. 対象校数・学級数・端末台数が本見積の前提から変動する場合、金額が変動します。
4. **Google Workspace for Education** の利用料およびChromebook本体の調達費は本見積に含まれません。
5. Chrome ウェブストアの審査に要する期間および審査結果は当方の管理外であり、金額に影響しませんが、導入時期に影響する場合があります。
6. 現地訪問を伴う作業は、別途〔旅費交通費〕を申し受けます。
7. 本見積は「①システム企画・機能仕様提案書」「③ソフトウェア利用規約・SLA合意書」「④個人情報保護および情報セキュリティ管理説明書」と一体で提示するものです。
