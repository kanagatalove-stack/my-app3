# Chromebook 児童端末管理システム（美作市14校対応・教員認証付き）仕様 & セットアップガイド

本システムは、Googleスプレッドシート（ID: `1_zSGoaoyUqMNHY0rxuITIk25yAHDT7qrZwIj_024fPs`）をデータベースとし、**美作市内14校の小中学校**のChromebook児童端末を一括管理できる教員用WebコンソールおよびManifest V3準拠のChrome拡張機能です。

教員Googleアカウント＋パスワードによるログイン認証機能を備え、学校ごとの絞り込みやクラスごとの一括制御が可能です。

## 📊 スプレッドシート設計（2つのシート）

対象スプレッドシート: [スプレッドシートを開く](https://docs.google.com/spreadsheets/d/1_zSGoaoyUqMNHY0rxuITIk25yAHDT7qrZwIj_024fPs/edit)

### 1. シート「`端末一覧`」（児童端末DB）

| 列 | ヘッダー名 | 型 / 形式 | 説明 / 設定例 |
|:---:|---|---|---|
| **A** | `児童ID` | 文字列（必須・一意） | 児童識別番号またはメアド（例: `aida-es-001`, `student01@school.ed.jp`） |
| **B** | `学校名` | 文字列 | 14校のいずれか（例: `第一小学校`） |
| **C** | `氏名` | 文字列 | 児童生徒氏名（例: `山田 太郎`） |
| **D** | `クラス` | 文字列 | クラス名（例: `5年1組`, `2年A組`） |
| **E** | `画面ロック` | 真偽値 (`TRUE` / `FALSE`) | `TRUE` で児童端末の画面が全画面ロック（キー・マウス無効化） |
| **F** | `URL規制モード` | `OFF` / `WHITELIST` / `BLACKLIST` | ・`OFF`: 規制なし<br>・`WHITELIST`: 許可URLのみ閲覧可<br>・`BLACKLIST`: 規制URLを閲覧拒否 |
| **G** | `許可URLリスト` | カンマ区切り文字列 | ホワイトリストURL（例: `nhk.or.jp, scratch.mit.edu`） |
| **H** | `規制URLリスト` | カンマ区切り文字列 | ブラックリストURL（例: `youtube.com, twitter.com`） |
| **I** | `一斉表示URL` | URL文字列 | 教員が児童に一斉に開かせたいURL（例: `https://scratch.mit.edu`） |
| **J** | `一斉表示実行ID` | 文字列 | 再配信検知用ID（例: `bc_1727180000000`）※システム自動生成 |
| **K** | `現在開いているURL` | URL文字列 | 拡張機能から定期報告される最新URL |
| **L** | `最終同期日時` | 日時文字列 | 拡張機能からの直近通信時刻（60秒以内でオンライン判定） |
| **M** | `備考` | 文字列 | 管理メモ（例: `Chromebook #01`） |

## 🚀 セットアップ手順（GAS & デプロイ）

### 1. Apps Script のセットアップ
1. スプレッドシート（ID: `1_zSGoaoyUqMNHY0rxuITIk25yAHDT7qrZwIj_024fPs`）を開きます。
2. **「拡張機能」 > 「Apps Script」** を開きます。
3. `Code.gs` に [gas/Code.gs](file:///workspaces/my-app3/gas/Code.gs) の内容を貼り付けます。
4. 「＋」 > 「HTML」で `index` を作成し、[gas/index.html](file:///workspaces/my-app3/gas/index.html) の内容を貼り付けます。
5. ツールバーの関数で **`setupSpreadsheet`** を選択して **「実行」** をクリックします。
   - `端末一覧` シートに14校のサンプル児童データ（14名分）が投入されます。
   - `教員マスタ` シートに上記3アカウントが自動投入されます。

### 2. Webアプリとしてデプロイ
1. 右上の **「デプロイ」 > 「新しいデプロイ」** をクリック。
2. 種類: **「ウェブアプリ」**
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**（児童端末の拡張機能から認証なしでハートビートを送るため）
3. 発行された **WebアプリURL** をコピーします。

## 💻 教員用管理コンソールの使い方

1. 発行されたWebアプリURLをブラウザで開きます。
2. **教員ログイン画面**が表示されます。
   - 例: `admin@school.ed.jp` / `Admin1234!` を入力して「ログイン」
3. **ダッシュボード画面**:
   - 上部の「学校」ドロップダウンで対象校（14校または全校）を選択します。
   - 「クラス」ドロップダウンで対象クラスを絞り込みます。
   - **一括画面ロック (ON/OFF)**: 選択した児童の画面を即座に「ロック中：先生の話を聞きましょう」で覆い、キーボード入力を無効化します。
   - **一斉URL配信**: URL（NHK for School、Scratch等）を入力して送信すると、児童端末側で自動的にそのページが開きます。
   - **URL規制変更**: ホワイトリスト（指定外すべて禁止）またはブラックリスト（指定Webサイトのみ禁止）を適用できます。
   - **現在閲覧中URLの見守り**: 児童が今どのページを開いているかがリアルタイムで一覧表示されます。

## 🧩 Chromebook児童端末（拡張機能）の設定

1. 児童端末のChromeで `chrome://extensions` を開き、デベロッパーモードで [extension/](file:///workspaces/my-app3/extension) フォルダを読み込みます。
2. 拡張機能ポップアップを開きます。
3. **児童ID**（例: `daiichi-es-001`）と **GAS WebアプリURL** を入力して「保存」します。
4. 自動的にスプレッドシートと同期され、所属学校名や児童氏名が拡張機能画面に表示されます。
